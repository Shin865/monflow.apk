# Money Flow

Aplikasi pencatatan keuangan pribadi untuk Android. Semua data disimpan di ponsel sendiri, tidak perlu internet, tidak ada iklan.

## Unduh

Ambil file APK di halaman **[Releases](https://github.com/Shin865/monflow.apk/releases)**.

| File | Keterangan |
|---|---|
| `MoneyFlow-universal-release.apk` | Bisa dipasang di semua perangkat Android (pilih ini kalau tidak yakin) |
| `MoneyFlow-arm64-v8a-release.apk` | Untuk HP Android modern 64-bit, ukuran file lebih kecil |
| `MoneyFlow-armeabi-v7a-release.apk` | Untuk HP Android lama 32-bit |

### Cara pasang

1. Unduh file APK lewat browser HP.
2. Buka file yang sudah diunduh.
3. Kalau muncul peringatan, izinkan instalasi dari sumber tidak dikenal di Pengaturan.
4. Tekan **Pasang**.

## Apa saja yang bisa dilakukan

### Rekening & Dompet

Catat saldo di berbagai tempat — uang tunai, rekening bank, e-wallet, atau kantong lain yang Anda punya. Bisa pindahkan saldo antar akun, dan saldo masing-masing akan ikut berubah otomatis.

### Transaksi Harian

Catat pemasukan dan pengeluaran. Setiap transaksi punya kategori, tanggal, dan catatan. Tersedia kategori bawaan yang bisa Anda ubah atau tambah sendiri.

### Hutang & Piutang

Catat uang yang Anda pinjam atau yang dipinjam orang lain. Bisa catat cicilan pembayaran, dan sisa hutang/piutang otomatis dihitung.

### Deposito

Hitung simulasi bunga deposito berjangka. Mendukung bunga sederhana (simple) maupun bunga berbunga (compound), termasuk potongan pajak.

### Rencana Pembelian

Buat daftar barang yang ingin dibeli. Ketika sudah dibeli, bisa langsung direalisasikan jadi transaksi pengeluaran dari akun yang dipilih.

### Laporan Excel

Ekspor data keuangan ke file Excel (.xlsx) yang berisi beberapa sheet — transaksi, akun, hutang/piutang, dan lainnya. Berguna kalau ingin mengolah data lebih lanjut di komputer.

### Backup & Restore

Simpan cadangan seluruh data ke file, dan kembalikan kapan saja. Bisa dipakai untuk pindah ke HP baru atau sekadar jaga-jaga.

### Tema

Pilih tampilan terang (light), gelap (dark), atau ikuti pengaturan sistem.

### Keamanan

Kunci aplikasi dengan PIN atau sidik jari supaya orang lain tidak bisa membuka catatan keuangan Anda.

## Privasi

Aplikasi ini tidak mengirim data ke mana pun. Tidak ada server, tidak ada akun login, tidak ada analitik. Semua catatan keuangan tersimpan di penyimpanan lokal ponsel Anda saja.
